GeoCards

Country statistics, drawn as cards you can download. Figures come from live data; no country name ever appears on a card.

Pick from the suggestions as you type, or press Enter: English names, local names and ISO codes all work, and near-misses get matched. The field empties once the cards are drawn, so the answer stays off screen.

    Reference data

    A key adds fourteen fields the open data set does not carry, among them time zones, driving side, the working week, local number formatting and bloc memberships. It costs three requests per session out of the free plan's 500 a month.

    REST Countries blocks browser requests unless this page's hostname is on the key's allowed origins, so add the host you open this page from on the API Keys page: your GitHub Pages host (for example yourname.github.io) and, for local development with npm run dev, localhost. The key itself is never part of the page or the repository.

    Remembering the key writes it to this browser’s local storage in plain text. It is shared with the other geo apps on this site, so it only needs entering once, but any other page served from the same origin can read it. Leave that unticked on a shared machine. Forget key wipes it from the page and from storage straight away, for every app; without it the key is only ever held in memory for this tab.

    Pick a country on the left to build its card set.

    Out of the box, names, codes, area, languages, currencies, borders and capitals come from the mledoze/countries ISO 3166 data set, used under the ODbL and loaded once per session from a public CDN. Supply a REST Countries v5 key and that half is served from their API instead, which carries fourteen further fields. Figures that change year to year — population, GDP, life expectancy, rainfall, forest cover — come live from the World Bank open data API. Elevation, coastline, terrain, climate and natural resources come from the CIA World Factbook, in the public domain; the CIA discontinued it in February 2026, so those cards are a frozen final edition rather than current reporting.
