Check every ready-made chart

Loads all ready-made charts one by one and reports which fail and which column each one parses to. OWID renames charts from time to time, so this is how you find dead slugs. It downloads a lot of data and takes a few minutes.

2 — Countries

Type a name or ISO code, then pick with Enter or a click. Click a chip to remove it. Up to 8 series are drawn at once.

4 — Years

5 — Options

Exported PNG is always 2400 × 1600 px. Transparent keeps text and lines, drops the fill.

6 — Legend in the PNG

One label per colour. Leave a box empty to use the country's name, or type your own — “Country A”, say.

    Without it, the PNG shows no country names, so it works as a quiz clue.
