Geo apps

clue generators for a geography guessing game. Each one turns a country into something to recognise — a sheet, a chart, a shape — without naming it.

Saved API keys

Some apps can use a personal API key. Save it once here, or tick “remember” in the app, and every app on this site picks it up. Keys stay in this browser only; they are never uploaded anywhere but to the service itself.
